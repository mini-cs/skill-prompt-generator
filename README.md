# 개발자 프롬프트 생성기

Claude Skill 아이디어와 조건을 폼에 입력하면, SKILL.md 설계를 요청하는 프롬프트를 실시간으로 조립해 줍니다. 복사해서 Claude 채팅에 붙여넣으면 됩니다. 페이지가 AI를 직접 부르지는 않습니다.

**바로 쓰기:** https://ski11-prompt-generator.netlify.app/

## 사용 방법

1. **기본** 섹션에 스킬 아이디어를 적고 대상 플랫폼(Claude Code / claude.ai / 둘 다)을 고릅니다. 처음이라면 [예시로 채우기]로 어떤 값이 들어가는지 먼저 보세요.
2. 필요하면 **동작**(호출 방식, 트리거, 인자, 허용 도구)과 **예시·금지사항** 섹션을 채웁니다. 비워둔 칸은 Claude가 제안합니다.
3. 오른쪽(휴대폰은 아래쪽) 미리보기를 확인하고 [프롬프트 복사]를 누릅니다.
4. 새 Claude 대화에 붙여넣으면 폴더 구조, SKILL.md, 설치 방법, 테스트 방법, 규칙 셀프 체크를 받습니다.

- 스킬 이름이나 Bash 패턴 형식이 틀리면 칸 아래에 이유가 나오고 복사가 막힙니다.
- 대상 플랫폼에서 지원하지 않는 칸은 흐려지고 프롬프트에서 빠집니다. 입력값은 지워지지 않아서 플랫폼을 되돌리면 그대로 돌아옵니다.
- 입력은 브라우저에 자동 저장됩니다. [예시로 채우기]·[초기화]는 5초 안에 [되돌리기]로 취소할 수 있습니다.

## 로컬 실행

- VS Code의 Live Server 확장으로 `index.html`을 열거나,
- 프로젝트 폴더에서 `python -m http.server 8000`을 실행한 뒤 http://localhost:8000 에 접속합니다.

`index.html`을 더블클릭해서(`file://`) 열면 동작하지 않습니다. 브라우저가 파일 주소에서는 ES 모듈을 불러오지 않기 때문입니다.

## 배포 (Netlify)

이 GitHub 저장소가 Netlify에 연결되어 있어서 `main`에 push하면 https://ski11-prompt-generator.netlify.app/ 에 자동으로 배포됩니다. 빌드 단계는 없고 배포 폴더는 루트(`.`)입니다.

설정은 `netlify.toml`에 있습니다. 개발 문서(`docs/`, `tests/`, `CLAUDE.md`, `.claude/`, `package.json`)는 저장소에서는 공개되지만 배포된 사이트에서는 404로 숨깁니다.

배포 사이트는 HTTPS라서 휴대폰에서도 복사가 됩니다. 로컬 서버를 `http://<내 IP>:8000`처럼 다른 기기에서 열면 보안 연결이 아니라 클립보드를 쓸 수 없고, 미리보기를 전체 선택한 뒤 직접 복사하라는 안내가 대신 나옵니다.

## 테스트

```bash
npm test
```

Node 내장 테스트 러너(`node --test`)를 씁니다. 설치할 의존성은 없습니다.

## 폴더 구조

| 위치 | 내용 |
| --- | --- |
| `index.html`, `css/base.css` | 화면 뼈대, 색·글자·간격 변수, 공통 스타일 |
| `js/main.js` | 시작점. 상태 저장소를 만들고 등록된 기능을 차례로 불러옵니다 |
| `js/store.js`, `js/bind.js` | 상태 저장소, 폼 입력칸과 상태의 양방향 연결 |
| `js/data/` | 폼 기본값, 칸 정의, 예시 데이터, 프롬프트 규칙 문구(`rules.js`) |
| `js/lib/` | 공통 도구(쉼표·줄 단위 목록 파싱) |
| `features/<기능명>/` | 화면 기능 하나씩. 목록과 순서는 `features/registry.js` |
| `tests/` | 순수 함수 테스트와 예시 프롬프트 고정본 |
| `docs/superpowers/` | 설계 스펙과 구현 계획 |

프롬프트에 들어가는 규칙 문구는 2026-10-26에 공식 문서로 확인한 내용이며 `js/data/rules.js`에만 있습니다. 문서가 바뀌면 이 파일만 고칩니다.

## 기능 추가하는 법

1. `features/<기능명>/index.js`를 만들고 `export function init(ctx)` 하나만 내보냅니다. `ctx`는 `{ store, root, rules, defaults, example }`입니다.
2. 스타일이 필요하면 같은 폴더에 `style.css`를 둡니다.
3. `features/registry.js`에 한 줄을 등록합니다.
   ```js
   { name: '<기능명>', load: () => import('./<기능명>/index.js'), css: true },
   ```

기능끼리 서로 import하지 않고, 정보는 `store`로만 주고받습니다. 화면과 무관한 로직은 순수 함수 파일로 분리하고 `tests/`에 테스트를 둡니다.
